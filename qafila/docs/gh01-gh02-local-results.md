# نتائج التشغيل المحلي: GH-01 وGH-02

**التاريخ:** 22 أغسطس 2026
**نطاق التنفيذ:** محلي فقط داخل `/home/ubuntu/qafila-deterministic-gate`.
**النشاط الخارجي:** لا توجد عمليات GitHub أو MCP أو بريد أو شبكة؛ السياسة تسجل `network_egress: deny`.

## GH-01 — حتمية فاحص البوابة

شُغّل fixture صالح واحد مرتين باستخدام المخطط `qafila-event.v1` والسياسة `qafila-governance-policy.v1`. كلتا الجولتين قبلتا الحدث، ثم قارنت أداة منفصلة الحقول الحتمية فقط: `fixture_id`، ونسخة السياسة، والحالة، وسبب الحجب، و`payload_hash`، و`receipt_hash`، وحالة الخروج للشبكة. لم تدخل تسمية الجولة أو المعرف التجريبي في المقارنة لأنها بيانات تشغيل متغيرة لا تدل على عدم الحتمية.

| الجولة | Fixtures | Allow | Hold | نتيجة المقارنة |
|---|---:|---:|---:|---|
| `run-a` | 1 | 1 | 0 | خط الأساس |
| `run-b` | 1 | 1 | 0 | مطابق لـ`run-a` في الحقول الحتمية |

> **النتيجة:** تطابقت البصمة والإيصال الحتميان في تشغيلين محليين لمدخل ثابت. هذا يثبت قابلية إعادة المسار المحدد محلياً، ولا يثبت بعد اتساق كل أنظمة التشغيل أو كل runners أو أي نموذج توليدي.

## GH-02 — حجب الحالات السلبية

شُغّلت عشر fixtures سلبية. أعاد الفاحص `hold` لكل حالة وسجل سبباً معيارياً وإيصالاً حتمياً في `hold_register.jsonl`.

| نوع المخالفة | العدد | سبب الحجب المسجل |
|---|---:|---|
| مصدر مرجعي مفقود أو مخطط/حالة غير صالحة أو خاصية غير معلنة | 4 | `schema_invalid` |
| locator أو source hash مفقود | 2 | `provenance_missing` |
| مصدر خارج allowlist | 1 | `source_not_allowed` |
| payload hash غير مطابق | 1 | `payload_hash_mismatch` |
| idempotency key غير مطابق | 1 | `idempotency_key_mismatch` |
| عملية كتابة ممنوعة | 1 | `operation_denied` |
| **الإجمالي** | **10** | **10/10 hold** |

> **النتيجة:** حققت حزمة fixtures الحالية معدل حجب 100% للحالات السلبية المعرفة، قبل أي Adapter أو استدعاء شبكي. هذا يثبت فاعلية السياسة المحددة في هذه الحزمة، ولا يعني اكتشاف كل فئة خطأ مستقبلية من دون توسيع fixtures.
